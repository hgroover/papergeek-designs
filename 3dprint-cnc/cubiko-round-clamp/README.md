Cubiko round clamp

This is made to be secured to the Cubiko platform using M5x14 screws.
Only one of the two clamp pieces needs to be secured using 2 or 3 M5x30 screws.

This should be printed ideally using nylon but PLA will work. Use the finest layer setting (tested with 0.12),
80% infill, and 6 walls instead of 3 with 7 top/bottom layers. The screws and baseplate need brims. 

The clamp inserts may be printed with normal layer height (0.20) but should use the same strength settings as above.
Inserts should be printed with the V facing down.
There are two heights of clamp inserts. The 15mm height will be flush with the top of the clamp blocks, and the 18mm height will go 3mm above.

Initial assembly  with the screws will be a bit stiff. Work the screws all the way in.
After this they should still be slightly stiff but should be adjustable with fingers only.
There is an optional accessory which should fit in any drill. Do not overtorque the screws -
this is only meant to speed the very long initial threading process.

An optional TPU layer may be used to improve jaw traction with smooth pieces like metal.

For actual assembly, the following order is recommended:
1. Thread the screws into the clamp block starting on the side away from the notch.
   Screws should go all the way through until the shaft rotates freely
2. Thread the screws into the other clamp block with the notch facing. The clamp blocks
   are different in the direction of the thread only. Thread the other clamp block
   just enough so the ends of the screws are flush with the other side of the clamp block.
3. Slide the clamp blocks with screws onto the rail slots in the baseplate.
4. Secure the clamp block with the screw nobs to the aluminum baseplate using 3 M5x30 screws.
   This clamp block will remain stationary and the screws will pull the other clamp block in.
   The rails will not fully ensure alignment so it is necessary to tighten the knobs a little
   at a time in alternation.
   
With rails:
Max length of stock (no inserts): 125mm
Max width of stock: 51mm
Max height of stock: 24mm

Without rails (simple):
Max height of stock: 32mm
